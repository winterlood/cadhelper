# CAD작업 폴더 (CadHelper)

이 폴더는 인테리어 도면·SketchUp·견적·3D 작업 전용 Codex 프로젝트다. 설치 프로그램이 만든 파일이다.

- 여기서 오는 요청은 모두 인테리어 업무다. 전역 AGENTS.md 의 **CAD도우미 규칙**과 `ch-` 스킬을 그대로 따른다.
- 도면은 AutoCAD/SketchUp에 **지금 열려 있는 파일**을 기준으로 한다. 도면 파일이 이 폴더 밖(내 문서, 바탕화면, 카카오톡 받은 파일, 다운로드, D: 드라이브 등)에 있어도 된다. 파일을 이 폴더로 옮기거나 복사하라고 하지 않는다.
- 결과물(엑셀·3D·사진)은 CAD도우미 도구가 `CadHelper\output` 에 만든다. 이 폴더의 `결과물` 바로가기로 열 수 있다.
- 이 폴더의 파일을 지우거나 정리하지 않는다.
