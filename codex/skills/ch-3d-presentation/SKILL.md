# 고객 설명용 3D 만들기

## 순서
1. `learn_read` → 회사명(org), 기본 천장고, 선호 색·자재 확인. 천장고를 모르면 물어본다.
2. **AutoCAD 도면이 있으면 반드시 `scene_draft_from_cad(ceiling_mm=천장고)` 를 먼저 호출**한다. 벽·실별 바닥·창 개구부·문·가구(침대 매트리스 포함)·한글 실명·면적 요약·자재표·배지가 들어간 완성형 초안 JSON이 만들어진다. 손으로 처음부터 쓰지 않는다 (품질이 들쭉날쭉하고 토큰이 많이 든다).
   - 벽/창/문/가구 레이어 이름이 특이하면 `cad_overview` 로 확인해 wall_layers 등으로 지정해 다시 호출.
3. 초안 JSON을 읽고 **판단이 필요한 부분만** 고친다: title·notes(고객용 쉬운 말), 사용자가 원하는 자재·색, 빠진 가구 추가, 이상한 객체 삭제. 좌표는 건드리지 않는다. 저장은 UTF-8(BOM 없이). 도면이 없으면 `scene_format_help` 를 읽고 직접 작성.
4. `scene_build_html` → `open_file` 로 열어 확인 → 아래 품질 기준을 하나씩 대조해 부족하면 JSON을 고쳐 다시 만든다.
5. 요청 시 SketchUp: 새 파일을 열게 한 뒤 `sketchup_build_scene` (확인창) → `sketchup_capture` → `sketchup_save_copy`
   AutoCAD 3D: `scene_build_dwg` → `open_file`
6. 완성 HTML은 카톡/메일로 그대로 보내면 고객이 더블클릭으로 본다고 안내.

## 시공법 (말하지 않아도 항상 포함)
3D 페이지에는 **시공법 패널**이 자동으로 들어간다: 고객이 벽·바닥을 클릭하면 단면(바탕 → 마감)과 "1단계 … 5단계" 자재가 하나씩 붙는 순서가 나오고, ▶ 순서대로 버튼으로 애니메이션처럼 넘겨 볼 수 있다.
- 자동 연결 규칙: 벽 material "도장"→벽 도장, "벽지"→벽 도배, "타일"/욕실 벽→욕실 벽 타일, 이름에 "가벽"→경량 가벽 / 바닥 "강마루"→강마루, "타일"→타일 바닥, 이름에 욕실·화장실→욕실 바닥(방수 포함).
- 그래서 **자재를 정확히 넣는 것**이 곧 시공법이 된다: 사무소가 벽을 도배로 하면 벽 material 을 "벽지"로 바꾼다 (선호를 모르면 한 번 묻고 `learn_note` 로 저장). 욕실 바닥 name 에 "욕실"이 들어가게 한다. 새로 세우는 벽은 name 에 "가벽".
- 사무소 고유 방식(예: 강마루 대신 SPC, 방수 3회, 석고보드 1겹)이 있으면 scene 최상위에 "methods" 로 덮어쓴다:
  `"methods": {"바닥_강마루": {"title": "SPC 바닥 (비접착)", "side": "floor", "layers": [{"name": "…", "t": 5, "color": "#c8a27a", "how": "…"}], "note": "…"}}`
  (키: 바닥_강마루 바닥_타일 욕실_바닥 벽_타일 벽_도장 벽_도배 가벽 · layers 는 바탕부터 마감 순서 · how 는 고객용 쉬운 말)
- 특별한 부분(아트월, 탄성코트 발코니 등)은 그 객체에 "construction": {같은 형식} 또는 "construction": "키" 를 직접 넣는다.
- 바뀐 방식은 `learn_note`(분류: 시공법) 로 남기고 다음부터 같은 methods 를 넣는다.
- 답할 때 "벽이나 바닥을 클릭하면 시공 순서가 나온다"고 한 줄 안내한다.

## 품질 기준 (최소 이 수준 — 하나라도 빠지면 미완성)
- [ ] **벽체**: 도면 벽선 좌표 그대로 kind "wall" (두께 = 도면 벽 두께, 모르면 외벽 200 / 내벽 120). material "도장".
- [ ] **바닥 마감 구분**: 실마다 kind "prism" 바닥 (z0 0, z1 10) — 거실·침실 "강마루", 주방·현관·욕실·다용도 "타일", 발코니 "타일"(밝은 회색 color). 각 바닥 spec에 자재 규격.
- [ ] **창호**: 외벽 창 위치마다 kind "window" (a,b = 창 양 끝, 거실 sill 300/height 2000, 방 sill 900/height 1350). 도면 A-WINDOW 레이어나 외벽 개구부에서 찾는다.
- [ ] **문**: 모든 방·욕실·현관에 kind "door" (경첩 위치 x,y, width 900(욕실 800, 현관 1000), angle_deg = 열린 방향).
- [ ] **가구 디테일** (box 여러 개를 겹쳐 표현):
  - 침대 = 프레임(목재, 높이 380) + 매트리스(패브릭, +220) + 베개 2개(화이트) + 헤드보드
  - 소파 = 좌판(패브릭, 420) + 등받이(앞쪽 얇은 box, 800) + 거실 테이블 + TV장
  - 식탁(목재, 720) + 의자 4~6개(패브릭, 450)
  - 붙박이장/드레스룸 수납(화이트, 높이 2,200)
- [ ] **주방·욕실 설비**: 주방 하부장(화이트 850, 상판 인조대리석), 상부장, 냉장고 / 변기·세면대(위생도기), 욕조 또는 샤워부스(유리).
- [ ] **공간명** label (실 중앙).
- [ ] 모든 객체에 **name과 spec** (예: "퀸 침대", "1,500 × 2,000 mm") — 마우스를 올리면 고객이 본다.
- [ ] **materials** 표(자재 제안·규격 5~8줄), **summary**(면적·천장고·구성), **notes**(고객 설명 3~6줄, 쉬운 말).
- [ ] 도면과 다른 추정값이 있으면 **badge** {"label":"치수 확인 필요","text":"…"} 로 솔직하게 표시.
- [ ] layers: 벽체 / 바닥 마감 / 창호 / 문 / 가구 / 주방·욕실 / 공간명 — 고객이 켜고 끌 수 있게.
- [ ] **시공법 패널**에 이 현장의 벽·바닥 종류가 다 나온다 (욕실이 있으면 욕실 바닥·벽 타일 포함). 열어서 한 번 클릭해 확인.
- [ ] 현장이 열려 있으면 결과물이 그 현장 결과물 폴더에 저장됐는지 확인.

## 주의
- 도면 좌표를 그대로 써서 치수가 도면과 일치해야 한다. 임의 비율 금지.
- 가구는 도면에 그려진 위치·크기를 우선, 없으면 표준 규격(침대 Q 1,500×2,000 / SS 1,100×2,000, 3인 소파 2,200×900, 식탁 1,600×800).
- 사용자가 고친 점(색, 자재, 가구 스타일)은 `learn_note`(선호)로 남기고, 두 번째 3D 요청부터는 `learn_save_skill` 로 이 사무소 전용 3D 절차를 저장한다.
