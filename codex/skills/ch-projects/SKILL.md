# 현장별 폴더로 일하기

폴더: `C:\work\projects\<현장 이름>\` — `도면\`(DWG·DXF·SKP), `자료\`(사진·PDF), `결과물\`(엑셀·3D·PPT), `현장정보.md`(고객·주소·메모·기록)

## 순서
1. 사용자가 현장을 말하면 `project_open("신부평")` (일부 이름도 됨). 모르면 `project_list` 로 보여주고 고르게 한다.
   - 없는 현장이면 "새 현장으로 만들까요?" 묻고 `project_create(name, client, address, size, memo)`.
     이름은 사용자가 부르는 짧은 이름 (예: "신부평 32평 김철수").
2. 열면 나오는 **현장정보와 파일 목록을 먼저 읽고** 답한다 (지난번 결정·요청이 거기 있다).
3. 이후 만드는 결과물(엑셀·3D·PPT·캡처·DWG 사본)은 자동으로 그 현장 `결과물\` 에 저장된다.
4. 다른 현장 얘기가 나오면 바로 `project_open` 으로 바꾼다. 한 대화에서 여러 현장을 오가도 된다.
   지금 어느 현장인지 헷갈리면 답 첫 줄에 "(현장: ○○)" 를 붙인다.
5. 도면 파일:
   - 받은 파일 위치를 모르면 `project_find_files("*.dwg")` (카톡 받은 파일·다운로드·바탕화면·문서를 찾아봄)
   - `project_add_file(경로)` 로 현장 `도면\` 에 **복사**(원본은 그대로) → `project_open_drawing(파일명)` 으로 AutoCAD/SketchUp 에서 연다.
6. 고객 요청·결정·실측 치수·일정은 `project_note` 로 남긴다 (예: "안방 붙박이장 3m로 변경 요청", "11/20 철거 시작").
   사무소 전체 규칙·단가는 `learn_note`/`learn_set_prices`, 이 현장만의 내용은 `project_note`.

## 주의
- 현장 폴더의 파일을 지우거나 옮기지 않는다. 정리가 필요하면 사용자에게 말해 직접 하게 한다.
- `.codex`, `.cadhelper` 폴더는 건드리지 않는다.
