# 쓸수록 똑똑해지기

## 무엇을 저장하나
| 상황 | 도구 | 예 |
|---|---|---|
| 고쳐줌 / 선호 / 용어 | `learn_note` | [용어] "하지"는 벽체 각파이프 하지를 말함 |
| 단가를 알려줌 | `learn_set_prices` | 강마루 ㎡당 65,000원 |
| 회사 정보 | `learn_set_profile` | 상호, 연락처, 견적서 하단 문구, 기본 천장고 |
| 같은 요청 두 번째 / 어렵게 성공한 작업 | `learn_save_skill` | 이름 `room-area-excel`: 면적표 엑셀 만드는 정확한 절차 |

## 스킬 저장 기준
- 사용자가 실제로 만족한 절차만 저장한다.
- 단계마다 사용한 도구 이름, 인자(레이어 이름 등), 확인 방법, 주의점을 적는다.
- 이미 비슷한 `ch-learned-*` 스킬이 있으면 같은 이름으로 다시 저장해 갱신한다 (새로 만들지 않기).
- 저장 후 사용자에게 "다음부터는 이 방식으로 바로 하겠습니다" 한 줄로 알린다.

## 하지 말 것
- 비밀번호, 고객 개인정보(주민번호, 계좌)는 저장하지 않는다.
- 추측한 단가·규칙은 저장하지 않는다. 사용자가 말한 것만.
