# 도면 수치 질문에 정확히 답하기

1. `learn_read` (대화 처음 한 번) → 이 사무소의 레이어 규칙·관례 확인.
2. `cadhelper_status` 로 AutoCAD가 켜져 있고 원하는 도면이 열려 있는지 확인. 아니면 사용자에게 "AutoCAD에서 그 도면을 열어 주세요"라고 안내한다. 사용자가 파일 경로를 알려주면 `open_file` 로 열 수 있다.
3. `cad_overview` 로 **단위(mm인지)** 와 레이어 구성을 먼저 본다. 단위가 '단위없음'이면 치수 문자로 실제 크기를 검증한다.
4. 질문 종류별 도구
   - 실별 면적 / 전체 평수 → `cad_room_areas` (method="auto"). 결과 머리말의 [방법]을 확인.
     - 방 경계 폴리선이 있으면 그것을, 없으면 벽 선으로 방을 찾는다. 두 결과가 크게 다르면 사용자에게 확인.
     - 거실+주방처럼 트인 공간은 한 방으로 합쳐져 나온다는 점을 말해준다.
   - 특정 레이어의 면적/길이 합 → `cad_measure(layers="...")`
   - "이거 선택했는데 얼마야?" → 사용자가 AutoCAD에서 선택한 상태로 `cad_measure(source="selection")`
   - 문·창·가구·조명 개수 → `cad_blocks` (블록이 아니면 `cad_texts` 로 표기 문자 수를 세어 보조)
   - 실명·마감 표기 찾기 → `cad_texts(contains="...")`
5. 눈으로 확인이 필요하면 `capture_view`.
6. 답 형식: **핵심 숫자 먼저**(㎡와 평 둘 다), 다음 줄에 근거(방법·레이어·도형 수), 주의점 한 줄.
   예) "전체 실 면적은 179.0㎡(54.2평)입니다. (벽 선 61개로 방 12개를 찾아 합산, 벽 안쪽 기준)"
7. 표로 달라고 하면 `excel_table` 로 면적표 엑셀을 만들고 `open_file`.

주의
- 블록·외부참조 안의 도형은 합계에 안 들어간다. 의심되면 말한다.
- 해치와 폴리선이 같은 영역에 겹치면 이중 합산될 수 있다. `cad_measure(list_items=true)` 로 확인.
- 1평 = 3.3058㎡.
