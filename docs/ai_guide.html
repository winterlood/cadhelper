AI 처음 쓰는 분을 위한

AI 사용 안내서

Codex 같은 AI에게 일을 잘 시키는 방법과 조심할 점
세 줄 요약
  1. AI는 말 잘 알아듣는 신입 직원이라고 생각하세요.
  2. 구체적으로 시키고, 결과의 숫자는 한 번 확인하세요.
  3. 고객 개인정보·비밀번호는 입력하지 마세요.

1. AI는 이런 직원입니다

잘하는 것못하거나 조심할 것
  • 시키는 일을 빠르게 반복
  • 표 정리, 계산, 엑셀 만들기
  • 글 쓰기 (견적 설명, 고객 안내문)
  • 도면 숫자 재기 (CAD도우미 연결 시)
  • 가끔 그럴듯하게 틀린 답을 함
  • 현장 상황은 모름 (알려줘야 앎)
  • 말하지 않은 단가·규칙은 모름
  • 대화가 아주 길어지면 앞 내용을 잊기도 함
신입 직원에게 일을 줄 때처럼 무엇을, 어떤 기준으로, 어떤 형태로 원하는지 말해 주면 결과가 확 좋아집니다.

2. 일 잘 시키는 법

이렇게 말하기보다이렇게 말하면 더 좋아요
"견적 만들어줘""지금 열린 도면으로 거실·방 바닥 강마루 견적서 엑셀로 만들어줘. 발코니는 빼고"
"면적 알려줘""실별 면적이랑 전체 평수 알려줘. 욕실은 따로 표시해줘"
"3D 해줘""고객한테 보낼 3D 만들어줘. 천장고 2300, 거실 바닥은 밝은 원목색"
"이상한데?""침실1 면적이 너무 작아. 붙박이장까지 포함해서 다시 계산해줘"
  • 한 번에 하나씩 시키면 실수가 줄어듭니다.
  • 결과가 마음에 안 들면 어디가 왜 마음에 안 드는지 말해 주세요. 다시 만듭니다.
  • "어떻게 계산했어?"라고 물으면 근거를 설명합니다.

3. 숫자는 꼭 한 번 확인

AI는 계산 자체는 정확하지만, 어느 선을 방 경계로 볼지, 무엇을 포함할지는 잘못 판단할 수 있습니다.

  • 전체 평수가 평소 알던 값과 크게 다르면 → "어떤 기준으로 쟀어?"라고 묻기
  • 견적서에서 단가가 0원인 줄 → AI가 단가를 몰라서 비워 둔 것. 단가를 알려주세요
  • 고객에게 나가는 견적·면적은 최종 확인은 사람이 합니다

4. 대화 다루는 법

  • 새 일은 새 대화로 시작하면 헷갈리지 않습니다. (Codex에서 새 대화 버튼)
  • 같은 일을 이어서 할 때는 같은 대화에서 계속 말하면 됩니다.
  • AI가 엉뚱한 쪽으로 가면 "멈춰" 또는 "처음부터 다시"라고 말하세요.
  • CAD도우미는 중요한 것(단가·회사 정보·규칙)을 따로 기억하므로 새 대화에서도 이어집니다.

5. 요금(토큰) 이야기

AI는 쓴 만큼 사용량이 쌓입니다. 질문 하나는 아주 적게, 3D 만들기처럼 큰 일은 조금 더 씁니다.

  • 사용량이 다 차면 잠시 쉬었다 쓰라는 안내가 나옵니다. 고장이 아닙니다.
  • 같은 질문을 여러 번 반복하기보다, 한 번에 원하는 걸 정확히 말하는 게 아낍니다.

6. 보안과 개인정보

입력하지 마세요
  • 주민등록번호, 계좌번호, 카드번호
  • 비밀번호, 인증번호
  • 고객 연락처를 대량으로 붙여넣기
  • AI가 "이 파일을 지울까요?", "프로그램을 설치할까요?"라고 물으면, 무슨 뜻인지 모르겠으면 「아니요」.
  • 모르는 사람이 보낸 파일을 AI에게 열어보라고 시키지 마세요.
  • 도면 원본은 AI가 덮어쓰지 않게 설정돼 있지만, 중요한 도면은 따로 복사본을 두는 습관을 들이세요.

7. 자주 쓰는 말 모음

상황이렇게 말하기
처음 시작"지금 열린 도면 뭐가 있는지 알려줘"
근거 확인"어떻게 계산했어? 쉽게 설명해줘"
다시 하기"○○ 빼고 다시 해줘"
기억시키기"앞으로는 항상 ○○로 해"
기억 확인"지금까지 배운 거 보여줘"
파일 보기"방금 만든 거 열어줘" / "결과물 폴더 열어줘"
막혔을 때"CAD도우미 상태 확인해줘"

이 안내서는 CAD도우미와 함께 설치됩니다. 바탕화면에서 언제든 다시 볼 수 있습니다.
