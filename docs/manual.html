CAD도우미 사용설명서

AutoCAD · SketchUp · 엑셀 견적을 Codex에게 말로 시키는 방법

이 설명서 한 장만 기억하세요

  1. AutoCAD(또는 SketchUp)에서 도면을 연다
  2. Codex를 열고 하고 싶은 일을 말로 쓴다
  3. AI가 도면을 바꾸려 하면 확인창이 뜬다 → 괜찮으면 예, 아니면 아니요

1. CAD도우미가 뭐예요?

Codex(AI 프로그램)가 컴퓨터에 켜져 있는 AutoCAD와 SketchUp을 직접 보고, 재고, 만들 수 있게 연결해 주는 프로그램입니다.

할 수 있는 일예시
도면 숫자 묻기실별 면적, 전체 평수, 벽 길이, 문·창 개수
엑셀 만들기견적서(수식 포함), 면적표, 물량표, 자재표
3D 만들기고객에게 보낼 3D 설명 페이지, SketchUp 모델, AutoCAD 3D
SketchUp 집계재질별 면적(타일·도장·마루 물량), 가구 개수
도면 수정레이어 정리, 선 지우기, 치수 넣기 — 항상 허락을 받고 합니다

2. 처음 한 번만: 설치

  1. 받은 폴더에서 「설치하기」를 더블클릭합니다. (파란 창이 뜨면 추가 정보 → 실행)
  2. 검은 창에 글자가 지나갑니다. 5~10분 기다립니다. 인터넷이 연결돼 있어야 합니다.
  3. 「설치 완료!」가 나오면 엔터를 누릅니다.
  4. Codex를 완전히 껐다가 다시 켭니다. SketchUp도 껐다 켭니다.
  5. 바탕화면에 「CAD도우미 점검」, 「CAD도우미 결과물」 아이콘이 생깁니다.
점검하는 법 — 바탕화면 「CAD도우미 점검」을 더블클릭. [정상]이 나오면 됩니다. AutoCAD/SketchUp은 켜져 있을 때만 [정상]으로 나옵니다.

3. 매일 쓰는 법

AutoCAD 도면에 대해 물어볼 때

  1. AutoCAD에서 그 도면을 엽니다. (여러 개가 열려 있으면 지금 보고 있는 도면을 기준으로 합니다)
  2. Codex에 질문을 씁니다.

SketchUp 모델에 대해 물어볼 때

  1. SketchUp을 켜고 모델 파일을 엽니다. (시작 화면에서 멈춰 있으면 연결이 안 됩니다. 파일을 꼭 여세요)
  2. Codex에 질문을 씁니다.

4. 이렇게 말하면 됩니다

"지금 열린 도면 실별 면적이랑 전체 평수 알려줘"
"발코니 빼고 전용 면적만 다시 계산해줘"
"이거 선택했는데 면적 얼마야?" (AutoCAD에서 도형을 먼저 클릭해서 선택)
"이 도면으로 바닥 강마루랑 도배 견적서 엑셀로 만들어줘"
"면적표 엑셀로 뽑아줘"
"고객한테 보여줄 3D 만들어줘. 천장고 2300"
"그 3D 스케치업으로도 만들어줘"
"스케치업 모델에서 타일 들어간 면적 알려줘"
"A-DIM 레이어 전부 꺼줘" / "이 선들 지워줘"

말을 길게 쓸 필요 없습니다. 모르면 "어떻게 하면 돼?"라고 물어보세요.

5. 확인창이 뜨면

「CAD도우미 - 변경 확인」 창

AI가 도면이나 SketchUp 모델을 바꾸거나 지우려고 할 때만 뜹니다. 무엇을 바꾸는지 쓰여 있습니다.

  • 예 — 그대로 실행합니다.
  • 아니요 — 아무것도 바뀌지 않습니다. AI가 다시 물어봅니다.

잘 모르겠으면 항상 「아니요」를 누르세요. 손해 보는 일이 없습니다.

  • 처음 바꾸기 전에 원본 도면이 자동으로 백업됩니다. (내 문서 폴더 → CadHelper → backups)
  • 바뀐 게 마음에 안 들면 AutoCAD/SketchUp에서 Ctrl+Z 로 되돌릴 수 있습니다.
  • 도면 저장(Ctrl+S)은 AI가 하지 않습니다. 직접 하세요.

6. 결과물은 어디에?

엑셀, 3D 페이지, 사진은 모두 바탕화면 「CAD도우미 결과물」 폴더에 새 파일로 저장됩니다. 기존 파일을 덮어쓰지 않습니다.

3D 페이지(.html 파일)는 카카오톡이나 메일로 고객에게 그대로 보내면 고객이 더블클릭해서 볼 수 있습니다. 인터넷이 없어도 열립니다.

7. 쓸수록 똑똑해지게 하기

CAD도우미는 알려준 것을 기억합니다. 다음 대화에서도 그대로 씁니다.

이렇게 말하면기억하는 것
"앞으로 강마루 단가는 ㎡당 65,000원이야"견적서 단가 (다음부터 자동으로 들어감)
"우리 회사 이름은 ○○인테리어, 전화는 ○○○"견적서에 들어갈 회사 정보
"아니 그게 아니라, 발코니는 항상 빼고 계산해"계산 규칙
"우리는 도배 로스를 10%로 잡아"견적 규칙
"우리가 '하지'라고 하면 각파이프 하지야"사무소 용어

같은 종류의 일을 두 번 시키면, AI가 그 방법을 스킬로 저장해서 다음부터는 실수 없이 바로 합니다.

"지금까지 배운 거 보여줘"라고 하면 기억하고 있는 내용을 보여줍니다.

8. 문제가 생기면

증상해결
"AutoCAD에 연결할 수 없다"AutoCAD를 켜고 도면을 연 다음 다시 물어보기. AutoCAD에서 명령 실행 중(선 그리는 중 등)이면 Esc 두 번
"SketchUp에 연결할 수 없다"SketchUp에서 파일을 열었는지 확인. 그래도 안 되면 SketchUp 껐다 켜기
Codex가 CAD도우미를 모르는 것 같다Codex를 완전히 껐다 켜기 → 그래도 안 되면 「설치하기」 다시 실행
숫자가 이상하다"어떻게 계산했어?"라고 물어보기. 레이어 이름을 알려주면 더 정확해집니다
"AutoCAD LT라서 안 된다"고 나온다LT는 외부 연결이 막힌 버전입니다. 면적·3D는 도면을 DXF로 저장해서 보내 주면 처리할 수 있고, 엑셀 견적은 그대로 됩니다
AutoCAD가 여러 버전 깔려 있다지금 켜져 있는 AutoCAD에 자동으로 연결합니다. 원하는 버전을 켜 두세요
그래도 안 된다「CAD도우미 점검」 화면을 사진 찍어서 보내기

9. 지워야 할 때

받은 폴더의 「제거하기」를 더블클릭합니다. 결과물·백업·배운 내용은 남겨 둡니다.
